## Diagnóstico (archivado)

El componente `Auditoria` en `src/app/pages/admin/auditoria/auditoria.ts` llama a `AuditoriaService.getAll(100)` que hace:

```typescript
supabase.from('auditoria_pasaje').select('*, perfil:vendedor_id(nombre)').order('fecha', { ascending: false }).limit(limit)
```

**Problema**: La tabla `auditoria_pasaje` en Supabase tiene RLS habilitado pero **no existe una política SELECT** que permita al usuario autenticado ver todos los registros. Como resultado, `getAll()` devuelve `data: []` y la UI muestra "Sin registros" y totales en 0.

**Solución pendiente**: Crear políticas RLS en Supabase Dashboard (SQL editor) para `auditoria_pasaje`:
- `SELECT` para `authenticated` con `USING (true)`
- `INSERT` para `authenticated` con `CHECK (true)`
